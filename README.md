# Italian Food Order Admin

An administrator dashboard for managing an Italian food ordering restaurant. This application provides a clean, intuitive interface for restaurant administrators to view the menu, track customer orders, and schedule maintenance tasks.

## Features

### 🏠 Admin Home
- Dashboard with quick-access cards to navigate between sections
- Menu Management
- Customer Orders
- Maintenance Scheduling

### 🍕 Menu
- 10 Italian food items with detailed descriptions and pricing
- Includes appetizers, main courses, and desserts
- Responsive grid layout

### 📦 Customer Orders
- View online to-go orders
- Order status tracking (Pending, Preparing, Ready, Completed)
- Customer information, items ordered, total price, and pickup time

### 🔧 Maintenance
- Schedule and track restaurant maintenance tasks
- Priority levels (High, Medium, Low)
- Detailed information for each maintenance task

## How to Use

Simply open `index.html` in a web browser to view the application. No build process or dependencies required.

## Technologies Used

- HTML5
- CSS3 (with modern gradients and animations)
- Vanilla JavaScript (no frameworks)

## Design

- Fully responsive design that works on mobile, tablet, and desktop
- Modern purple gradient theme
- Smooth animations and hover effects
- Accessible semantic HTML structure
